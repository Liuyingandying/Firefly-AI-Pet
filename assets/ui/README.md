# assets/ui — UI V2 可替换资源目录

本目录存放「流萤 AI Pet 控制台」的可替换视觉资源。**代码不硬编码绝对路径**：
所有加载点使用 `Path(__file__)/../assets/ui/...` 相对解析；文件不存在时
自动回退到代码绘制的默认视觉（渐变背景 / 光环头像 / 矢量图标）。

## 目录约定

| 目录 | 文件 | 用途 | 替换后生效位置 |
|---|---|---|---|
| `background/` | `background.png` | 控制台主窗口背景（建议 1280×800+，深空蓝紫低饱和） | `theme.v2_background_style()` |
| `avatar/` | `liuying.png`（预留） | 流萤头像（当前为代码绘制光环占位） | Phase UI-3+ 头像组件 |
| `icons/` | （预留） | 能力入口自定义图标（当前为 emoji/矢量字形） | AbilityPanel / Sidebar |

## 约束

- 不放入任何版权素材；替换图片请自备授权。
- 替换文件名必须与上表一致（代码按固定文件名探测）。
- 图片缺失时 UI 必须仍能正常启动（回退为纯代码视觉）。
